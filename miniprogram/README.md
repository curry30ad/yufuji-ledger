# 微信小程序版说明

这个目录是当前熟食店记账系统的小程序版本骨架，已经接入现有后端接口，包含这些页面：

- 登录
- 首页总览
- 日记账
- 月报
- 经营分析
- 商品管理
- 店员管理

## 直接使用前需要处理的两件事

1. 把后端部署到公网 HTTPS
   - 小程序不能直接连 `127.0.0.1`
   - 需要一个可访问的 `https` 域名
2. 修改 `miniprogram/app.js` 里的 `baseUrl`
   - 现在是占位值：`https://your-domain.example.com`

## 导入方式

1. 打开微信开发者工具
2. 选择“导入项目”
3. 项目目录选这个文件夹：`miniprogram`
4. 用你自己的小程序 `AppID`
5. 在“开发管理 / 开发设置”里，把后端域名加入合法请求域名

## 说明

- 当前小程序版复用了现有账号密码登录和账目接口
- 店主和店员权限仍然按后端控制
- Excel 导出会通过小程序下载并调用系统打开
- 如果后续要正式上架，还需要补充微信登录、图标、隐私协议、域名备案等内容
