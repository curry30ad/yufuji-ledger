# 于福记熟食店记账系统

这是一个给熟食店日常记账和经营复盘使用的本地项目。当前主要使用方式是本地网页端，重点围绕门店录入、利润核算、支出分类、进货对账和经营总览。

## 当前重点

- 本地运行，默认访问 `http://127.0.0.1:3000`
- 以网页端为主，适合老板和店员日常使用
- 支持多门店和权限隔离
- 经营利润拆分为毛利润和实际利润
- 进货支持一单多商品，便于对账和回看
- 支出分类细化，便于看真实经营结果

## 已实现功能

- 账号密码登录
- 店主 / 店员权限区分
- 多门店数据隔离
- 经营总览
- 快速记营业
- 单品销售录入
- 进货单多商品录入
- 支出记录
- 日报、月报、区间统计
- 经营分析
- 商品管理
- 店员账号管理
- Excel 导出

## 利润口径

- 毛利润 = 销售总额 - 进货金额
- 实际利润 = 毛利润 - 支出

## 支出分类

当前支出分类包括：

- 进货支出
- 房租
- 水电
- 人工
- 包装耗材
- 平台抽成
- 配送费
- 其他日常支出

## 记账规则

- 如果退款和抹零都为 `0`，系统默认按 `销售总额 = 实际收款` 处理
- 历史数据库中符合这条规则的缺失数据已经回填
- 所有 update/delete 类接口都会校验记录归属
- 店员只能操作自己门店的数据
- 店主可以跨门店操作

## 本地启动

```bash
npm install
npm start
```

启动后访问：

```text
http://127.0.0.1:3000
```

## 默认账号

- 店主：`owner / admin123`
- 店员 1：`store1 / 123456`
- 店员 2：`store2 / 123456`

## 常用脚本

```bash
npm run smoke
npm run test:full
```

说明：

- `smoke`：基础接口和核心流程自测
- `test:full`：完整本地回归测试
- 测试统一使用独立临时数据库，不写入 `data/ledger.sqlite`

## 目录说明

- `server.js`：后端服务与接口
- `public/`：网页端静态资源
- `scripts/`：测试、回填和数据修复脚本
- `data/`：本地数据库与上传目录
- `miniprogram/`：保留中的小程序代码

## 数据修复脚本

当前仓库包含以下辅助脚本：

- `scripts/backfill-purchase-order-no.js`：补齐历史进货单号
- `scripts/reclassify-expenses-by-note.js`：按备注重分类支出类型
